# Country choices and geographic ranking

`countries.json` is a bundled snapshot of the public-domain IANA tzdb
`iso3166.tab` and `zone.tab` supplied by the operating system (2025 edition).
It includes all 249 ISO country/territory choices. Coordinates use the first
representative timezone location for each country, not an IP lookup or measured
latency. Missing locations get no distance-based adjustment.

Best value uses approximate geographic distance for a 0–15 point contribution.
The preferred GPU contributes another 5 points. These preferences never promise
network latency, change price, or bypass the shared launch compatibility checks.
