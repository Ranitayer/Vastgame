# Vastgame 1.1.10 — Sessions, working preferences and reviewed lifecycle safety

- Settings now fits the available window without page scrolling. Sensitive settings ends at the shared bottom page margin, with roomier action rows in tall windows. Save/Saved and Reset remain beside Settings; dropdowns scroll rather than paginate.
- Stream preferences configure Moonlight codec, decoder, color format, display mode, frame rate, resolution, frame pacing, VSync, audio and bitrate. Host preferences filter verified/minimum-resource offers and influence Best value using country/GPU preferences. The session spending limit is stored but deliberately not enforced yet.
- Sensitive settings provides verified force shutdown of Vastgame-labelled rentals and explicit session-history deletion. These destructive actions require confirmation. Private settings/account/game/save data are not included in the public download.
- Sessions records rental identity, full redacted logs, stage events, observed play time, rig details and provider-reported costs when available. Cards support filters/sorting, exact-rig reconnect/relaunch, right-side details and panel-contained Events/Logs with full-log/ID copy. Missing historical data remains unknown; estimates exclude bandwidth and adjustments.
- Account credit appears in the title bar through the shared read-only account helper. Home retains the selected-rig/progress pill, launch timer, responsive host rows, artwork caching and Play/Connect/shutdown controls.
- A quote arriving after Force shutdown all cannot rent a VM. Protected shutdown rechecks the original provider ID/launch label after backup. Legacy force aliases no longer create false sessions. Save/shader restores use shared private, unpredictable temporary files to prevent predictable-temp symlink write redirection.
- Updated README and system architecture; added desktop/ARCHITECTURE.md and the dated project review with remaining risks and 20 ranked improvements. Removed confirmed unused wrappers/aliases/branches without adding dependencies.

Existing installs: run `vastgame update`, then reopen the app; alternatively extract the ZIP and run `Update-Vastgame.cmd`. The updater preserves account data, games, saves and stream preferences. Fresh installs: extract `Vastgame.zip` and run `Vastgame.cmd`; private account setup and matching Tailscale enrollment are still required.

The download pairs the native x64 Windows app with its matching WSL backend. Linux's Ctrl+Shift+Q stream overlay/HUD remains Linux-only; Windows uses the included stream settings editor. Build publication does not rent or destroy a VM. Automated tests/type checks/lint and live GPU/Windows acceptance were not run under the current user preference. Regression cases were added for the reviewed safety changes; release publication requires a successful Windows build from this exact source commit.
